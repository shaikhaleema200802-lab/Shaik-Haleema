1.40 - 1.41 Exception Handling

Handling runtime errors using try, catch, throw, throws, and finally keywords.

Sentence: The finally block always executes regardless of exception handling.
try {
    int result = 10 / 0;
} catch (ArithmeticException e) {
    System.out.println("Divided by zero error!");
} finally {
    System.out.println("Execution finished.");
}
